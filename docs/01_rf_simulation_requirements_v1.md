# 射频仿真设计需求书（基础参数冻结版 V1）

## 1. 项目目标

开发用于微波加热设备的磁吸点板天线及连接件。灰板约 50 mm × 50 mm，支持 1–100 块组网。主机根据板数调整输出功率，单组最大前向功率标称 500 W。

本阶段仿真对象包括：

- 灰板；
- 平面连接桥；
- 立体直角桥；
- N 头 + 磁吸薄片 + 同轴连接线；
- 5 / 25 / 100 块级联系统。

目标不是只得到单板 S11，而是建立可追溯的功率分账：输入、反射、直通、有用取能、工件吸收、铜损、FR4/PP 损耗、连接损耗和末端功率。

## 2. 工作频率

| 参数 | 冻结值 |
|---|---:|
| 中心频率 | 2.45 GHz |
| 工作频段 | 2.40–2.50 GHz |
| 自由空间波长 | 约 122.4 mm |
| 全局扫频 | 2.0–3.0 GHz |
| 重点频段 | 2.40–2.50 GHz |
| VSWR≤2 目标带宽 | ≥50 MHz |

工作带宽内建议输出密集离散频点；谐振、急剧相位变化和 VSWR 峰值附近自适应加密。

## 3. 微波源与端口

| 参数 | 值 |
|---|---|
| 类型 | 磁控管 |
| 频率 | 2.45 GHz |
| 最大前向功率 | 500 W |
| 功率控制 | PWM / 0–10 V，根据板数调节 |
| 参考阻抗 | 50 Ω |
| 接口 | WR340 波导转 N 型同轴 |

### 3.1 500 W 的参考面

暂按“进入被评估射频系统的最大前向功率”处理。最终验收前必须明确参考面位于：

1. 磁控管/匹配器输出；
2. WR340→N 转换器输出；
3. 长同轴线之后；
4. 第一块灰板入口。

参考面不同，板链可用功率预算不同。

## 4. 材料参数

### 4.1 FR4

| 参数 | 标称值 |
|---|---:|
| εr | 4.3 |
| tanδ | 0.02 |
| 厚度 | 1.6 mm |

建议扫参：

- εr = 4.1 / 4.3 / 4.5
- tanδ = 0.015 / 0.020 / 0.025

不得只给 εr 而把 FR4 当成无损介质。

### 4.2 铜

| 参数 | 标称值 |
|---|---:|
| 电导率 | 5.8×10^7 S/m |
| 相对磁导率 | 1.0 |
| 厚度 | 35 μm |
| 表面粗糙度 | Rz=5 μm |

粗糙度应作为敏感性参数。若求解器使用 Huray/Groisse 等模型，应记录模型名称与转换参数，避免把 Rz 与 Rq 混用。

### 4.3 PP

| 材料 | 厚度 | εr | tanδ |
|---|---:|---:|---:|
| 透明 PP 前面板 | 2 mm | 2.2 | 0.0005 |
| PP 背板 | 6 mm | 2.2 | 0.0005 |

胶层、空气隙、涂层、机械压缩层若存在，必须单独加入模型。

## 5. 统一阻抗与传输线

所有端口采用 50 Ω 参考阻抗。

需要区分“系统目标 50 Ω”和“几何天然 50 Ω”。给定 1.6 mm FR4 与 2 mm PP 覆盖时，已有二维截面估算：

| 能量线宽 | 估算阻抗 |
|---:|---:|
| 1.5 mm | ≈68.0 Ω |
| 2.0 mm | ≈59.3 Ω |
| 2.5 mm | ≈52.8 Ω |
| 3.0 mm | ≈47.7 Ω |

因此三维设计可从约 2.7–2.9 mm 线宽附近开始细扫；2 mm 不应直接锁死为最终 50 Ω 尺寸。

## 6. 灰板

### 6.1 层叠与走线

- 外形：50 mm × 50 mm；
- 前面板：2 mm PP；
- FR4：1.6 mm；
- 背板：6 mm PP；
- FR4 正面：直通能量线 + 耦合段 + 方形螺旋线圈 + 识别线；
- FR4 背面：整片地铜；
- 识别电阻：10 kΩ；
- 识别线宽：0.3 mm；
- 识别线与能量线间距：≥1 mm。

### 6.2 初始优化变量

| 变量 | 初始范围 |
|---|---:|
| 耦合段长度 | 5–15 mm |
| 耦合间距 | 0.3–0.8 mm |
| 线圈圈数 | 2–4 |
| 主能量线宽 | 2.5–3.0 mm 起始扫描 |
| 线圈外径 | 待冻结 |
| 线圈线宽/匝距 | 待冻结 |
| 工件距离 | 待冻结 |

### 6.3 原始性能目标

| 指标 | 目标 |
|---|---|
| 单板 VSWR | ≤2.0 |
| 直通插损 | ≤0.5 dB |
| 单板取能 | 5–8 W |
| 3 cm 近场均匀性 | ≤±5 dB |
| 局部设计场强 | <1 kV/mm |

“直通插损”必须与“有用取能”分开记账。若取能支路从主线上抽走功率，S21 下降并不全是寄生损耗。

## 7. 平面连接桥

- 外形：100 mm × 50 mm × 30 mm；
- 壳体：PP；
- 内部：FR4 + 35 μm 铜；
- 背面整片地铜；
- 能量线原始宽度：2 mm；
- 识别线：0.3 mm；
- 能量线与识别线间距：≥1 mm。

原始目标：

- 插入损耗 ≤0.2 dB；
- VSWR≤1.5。

该目标需要与 FR4 损耗预算联合复核，不能只靠优化拐角或触点。

## 8. 立体直角桥

- L 型；
- 两边各 50 mm；
- 宽 50 mm；
- 高 30 mm；
- 原始圆角 R3–R5。

三维模型必须包含信号线与地平面的完整 90° 转折。仅建立正面铜线的 L 型路径不足以代表真实射频回流。

目标：

- 插入损耗 ≤0.3 dB；
- VSWR≤1.5。

## 9. 连接线

原方案：

- N 型母座；
- 磁吸薄片；
- 50 Ω 同轴；
- 候选 RG142；
- 长度 3–10 m；
- 2 芯屏蔽识别信号线。

原始目标：

- 3 m 插损 ≤0.3 dB；
- 5 m 插损 ≤0.5 dB；
- VSWR≤1.5。

RG142 暂列为候选，而不是已冻结可行型号。必须按实际料号、2.45 GHz 衰减、CW 功率额定和温度降额复核。

## 10. 系统组态

至少仿真：

- 单板；
- 5 块；
- 25 块；
- 100 块。

应覆盖真实空间排布，而不是只用无相位的标量插损相加。桥长、板间距、同轴长度和负载变化会改变级联相位及反射。

## 11. 输出与验收数据

每个工况至少保存：

1. 复数 S 参数；
2. S11 / S21 / 必要的耦合端口 S 参数；
3. VSWR；
4. 每个端口前向、反射、接受功率；
5. 每块有用取能；
6. 铜、FR4、PP、接触区域损耗；
7. 指定工件体积吸收功率；
8. 3 cm 评估面的 E 场热图；
9. 最大局部电场位置；
10. 表面电流密度；
11. 500 W 缩放结果；
12. 网格收敛记录；
13. Touchstone / CSV / 原生求解器工程文件。

## 12. 当前状态

**已冻结：**

- 2.45 GHz；
- 2.40–2.50 GHz；
- 2.0–3.0 GHz；
- 50 Ω；
- FR4 标称 εr/tanδ/厚度；
- 铜电导率/厚度/粗糙度；
- PP εr/tanδ/厚度。

- 胶层/气隙；
- RF 地触点/回流结构；
