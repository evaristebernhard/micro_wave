# Archive

This directory contains superseded development documents preserved for traceability.

Typical reasons for archival:

- 50 × 50 mm or obsolete 50 × 70 mm geometry assumptions;
- side-coupled / edge-coupled topology that is no longer the primary route;
- 0°/90°/180°/270° progressive-phase seed superseded by field-aware mirror excitation;
- equal-power tap values superseded by the current workpiece-aware target;
- old PCB manuals that predate the true 50 × 60 mm board and the full V2 engineering board;
- intermediate requirement revisions V1/V2.

Current design work should start from `../README.md`, `../24_theory_closure_master_v1.md`, and `../27_fast_tcell_design_loop_v1.md`.
