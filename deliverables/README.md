# Engineering deliverables

This folder is the handoff map for the current 2.45 GHz magnetic microwave-heating project.

## PCB / fabrication sources

- Main board: `pcb/tscircuit/index-full-v2.tsx`
- Flat bridge: `pcb/tscircuit/index-flat-bridge.tsx`
- Corner bridge: `pcb/tscircuit/index-corner-bridge.tsx`
- Cable magnetic tab: `pcb/tscircuit/index-cable-tab.tsx`

Gerber/PCB-SVG artifacts are generated by the tscircuit CI.

## EM models

- Full V2 board: `scripts/openems/simulate_full_v2_fast.py`
- Flat/corner/tab: `scripts/openems/simulate_connection_hardware.py`

## System models

- Cable loss: `scripts/system/cable_model.py`
- 5/25/100 power budget: `scripts/system/cascade_power_budget.py`

## Final report evidence table

The final customer report should include one row per requirement:

| Requirement | Evidence | Final status |
| --- | --- | --- |
| Full board S11 / VSWR | Full V2 openEMS screen/verify | pending final converged run |
| 5–8 W per board | network + loaded-workpiece result | pending loaded-workpiece calibration |
| ±25% uniformity | 5/25/100 cascade | model implemented; populate with final losses |
| Flat bridge IL ≤0.2 dB | flat bridge openEMS | model implemented; run pending |
| Corner bridge IL ≤0.3 dB | corner bridge openEMS | model implemented; run pending |
| 5 m cable IL ≤0.5 dB | cable audit | RG142 conflicts with target; replacement or target revision required |
| Manufacturing files | tscircuit CI Gerbers | generated once CI passes |

Do not mark a requirement Pass until its corresponding evidence file exists.
